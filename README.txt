# Bharathiraja Portfolio

Open `index.html` in a browser.

Before publishing:
1. Replace `assets/Bharathiraja_Resume.pdf` with your actual resume PDF.
2. Update the LinkedIn URL, GitHub URL, and email in `index.html`.
3. Upload the whole folder to GitHub Pages, Netlify, Vercel, or another static host.

The portfolio is a single-page responsive site with animated background, scroll reveal effects, interactive cards, terminal-style section, and your uploaded portrait.
